## 📌 Overview



AgriGenAI is an AI-powered smart agriculture platform that helps farmers make data-driven decisions using Machine Learning, Deep Learning, OCR, Generative AI, and Weather Intelligence.



The platform provides crop recommendations, plant disease detection, fertilizer suggestions, market price prediction, smart irrigation, AI chatbot assistance, soil health card analysis, agricultural news, government schemes, and an online marketplace.

# ⚡ Installation



## Clone Repository



```bash

git clone https://github.com/Basavaraj-55/AgriGenAI.git



cd AgriGenAI

```



## Backend



```bash

cd backend



python -m venv venv



venv\Scripts\activate



pip install -r requirements.txt



python app.py

```



## Frontend



```bash

cd frontend



npm install



npm run dev

```



---



# 🌍 Environment Variables



Create a `.env` file inside the backend folder.



```env

GEMINI_API_KEY=YOUR_API_KEY



MONGO_URI=YOUR_MONGODB_URI



DATABASE_NAME=AgriGenAI



JWT_SECRET_KEY=YOUR_SECRET_KEY



MAIL_EMAIL=YOUR_EMAIL



MAIL_PASSWORD=YOUR_APP_PASSWORD

```
